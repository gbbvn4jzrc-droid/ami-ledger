ami记账 · 隐私说明

版本 1.0

无付费、无广告、本地优先。

ami记账 PWA 不要求注册账号，不设置订阅、内购或广告，也不接入第三方分析服务。

你的账单、预算和设置使用浏览器 IndexedDB 保存在当前设备的 Safari / Web App 本地存储中，本应用不会主动把这些数据上传到开发者服务器。

你可以在设置中主动导出 CSV 或完整 JSON 备份。导出的文件由你自行决定保存或分享位置。

需要注意：浏览器本地存储并不等同于永久备份。卸载 Web App、清除 Safari 网站数据、系统清理存储或某些设备迁移场景都可能导致本地数据丢失，因此建议定期导出 JSON 备份。
